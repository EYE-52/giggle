## Run again

Use the supplied Playwright `NODE_PATH` and Chrome binary. Start the task-owned game server on 8400, then set `APP_FEEL_URL=http://127.0.0.1:8400` for the app-feel tools. `APP_FEEL_ARTIFACTS` can point at a fresh output directory.

From the worktree root:

```sh
NODE_PATH=/private/tmp/codex-driving-browser/node_modules FIT_PORT=8401 FIT_ARTIFACTS=artifacts/integration/container node apps/games/test/container-fit-browser.cjs
NODE_PATH=/private/tmp/codex-driving-browser/node_modules FIT_PORT=8402 FIT_ARTIFACTS=artifacts/integration/drawing-live node artifacts/narrow-fit/live.cjs
NODE_PATH=/private/tmp/codex-driving-browser/node_modules NODE_OPTIONS="--require=$PWD/artifacts/integration/ports.cjs" FIT_PORT=8403 npm --prefix apps/games test
```

The test preload maps automatic ephemeral listeners into 8404–8410, leaving all task listeners in the assigned 8400–8410 range. It rotates ports across server restarts so HTTP clients cannot reuse a closing socket. The first full-suite attempt exposed this helper issue in the report API check; its targeted rerun passed after fixing the helper. The final complete suite passed with the rotating helper. The helper does not change game code.
