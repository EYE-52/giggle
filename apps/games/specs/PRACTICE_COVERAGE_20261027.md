Owned-game practice coverage — 27 October 2026

All 42 owned games retain their real two- or three-player minimum. One person controls the real playing seats within one page. There are no bots, automatic answers or lower server minimums. Player choices exclude spectator-only slots and are capped at 8. Ordinary room credentials and signed Giggle embeds stay separate.

The desktop matrix passed entry, all-seat readiness, seat switching, keyboard navigation, optional all-seat view and server-acknowledged Leave/cleanup for 42/42 games. Trivia and Four in a Row also completed naturally; Four in a Row rematch and 300-point winner scoring passed. The other 40 natural completions are not claimed by this feature test. Mobile Chromium touch emulation passed 375×667 and667×375 for Trivia, Four in a Row and Pocket Karts; native browsers/devices are unrun.

Five local failure/recovery checks passed: configuration 503/retry, empty catalogue, blocked session storage and stalled module loading with both reduced-motion preferences. Only deliberately injected network failures are allowed; all other page/console errors fail the checks.

Timer ownership

The canonical app ships owned Pocket Karts. Smash Karts appears only in design/reference documents; no shipped external embed or timer-control integration was found. Pocket Karts uses the server-authoritative roundSeconds field, currently 60–300 seconds, default 180. The UI exposes 1–5 minutes;5-minute settings persisted and a selected 1-minute round reached the real local server. This patch does not change that range or claim control over the third-party game.

Source: games/engines/kart-engine.js, public/js/kart-setup.js and specs/POCKET_KARTS_SPEC.md. Publisher reference: https://play.google.com/store/apps/details?hl=en&id=com.tallteam.citychase .

All tests use task-owned local rooms and fixtures, no accounts or media permissions. Draw/performance notes distinguish controls walkthroughs and pretend judging from actual media acceptance. Scores from seeing all private seats are not fair competition. Practice rooms remain online and shareable by room code.

Aggregate/build verification and final candidate identity are recorded separately; this inventory does not claim a deployed feature.
