Who Wrote It

A little note, a little mystery

  • 3–20 players
  • Everyone plays
  • Customizable

How to play

Goal Match the anonymous notes to their writers.

  • Write a safe personal answer, then match the shuffled notes.
  • Use each player name once. Your own note needs no guess.
  • Correct matches earn up to 100; fooling readers adds up to 100.
All rules

Everyone writes an answer to a personal but safe prompt.

Match each anonymous note to a writer, using each name once and skipping your own note.

Score 100 times the share you get right, rounded.

Writers earn 25 for each wrong guess about their note, up to 100 extra.

Fewer than two notes skips the round.

3–20 players per room.

Make it yours

The host can adjust these before the game starts.

Room settings

  • Rounds 1–12, default 5
  • Pace Options: Relaxed · Normal · Quick. Default: Normal

Custom content

  • Custom prompts Bring your own (at least 5, up to 200, each ≤ 140 chars)
