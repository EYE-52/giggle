Whisper

One name. One coin. Will the secret escape?

  • 3–20 players
  • Everyone plays
  • Customizable

How to play

Goal Read the room, then call the coin.

  • Only the Whisperer sees the question before the coin flip.
  • Choose a name in time for 100. A correct coin guess also earns 100.
  • Heads opens the question. Tails keeps it secret, even at the end.
All rules

The Whisperer privately reads a kind question and picks a player in 20 seconds.

Everyone sees only that name.

Before the coin flips, everyone else guesses heads or tails.

A correct guess earns 100; choosing a name in time earns the Whisperer 100.

Heads reveals the question.

Tails keeps it secret forever.

Auto rounds gives everyone one turn as Whisperer.

3–20 players per room.

Make it yours

The host can adjust these before the game starts.

Room settings

  • Rounds 1–12, default One turn each
  • Pace Options: Relaxed · Normal · Quick. Default: Normal

Custom content

  • Custom questions Bring your own (at least 5, each ≤ 140 chars)
