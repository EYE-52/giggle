Doodle Guess

Draw it, friends guess it

  • 3–12 players
  • Everyone plays
  • Live drawing
  • Customizable

How to play

One player draws, everyone else guesses.

A correct guess is worth 100 points plus up to 100 for speed; the artist scores when the room gets it.

3–12 players per room.

Make it yours

The host can adjust these before the game starts.

Room settings

  • Rounds 1–12, default Auto (two per player)
  • Pace Options: Relaxed · Normal · Quick. Default: Normal
  • Seconds to draw 10–180, default 80
  • Timed letter hints (up to three) Default: on

Custom content

  • Custom words Bring your own (at least 10, up to 200, each ≤ 60 chars)

Start a room

Pick a name, create a room, and invite your friends. No account needed.
