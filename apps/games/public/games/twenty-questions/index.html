20 Questions

Yes/no your way to it

  • 3–12 players
  • Everyone plays
  • Customizable

How to play

Goal Guess the secret word in as few questions as you can.

  • Enter Send a question or guess
  • One player holds the secret word and answers Yes, No or Sometimes.
  • Ask yes/no questions, or guess the word at any time.
  • A correct guess scores 100, plus up to 100 for using fewer questions.
  • If nobody guesses it, the answerer scores 100.
  • If hints are on, each letter hint takes 50 off a correct guess.
All rules

Ask yes/no questions or guess the secret word.

The host chooses 10–50 questions per round (20 by default).

Optional shared letter hints cost 50 points each, up to two per round.

3–12 players per room.

Make it yours

The host can adjust these before the game starts.

Room settings

  • Rounds 1–12, default Auto (one per player)
  • Pace Options: Relaxed · Normal · Quick. Default: Normal
  • Seconds per round 30–600, default 180
  • Questions per round 10–50, default 20
  • Shared letter hints (50 points each, up to 2) Default: off

Custom content

  • Custom secret words Bring your own (at least 5, each ≤ 40 chars)
