Memory Tray

Memorize, recall, win

  • 2–20 players
  • Everyone plays
  • Customizable

How to play

Goal Remember the most tray items across all rounds.

  • Study the tray of 8 items before it hides.
  • Then type every item you remember, separated by commas.
  • Spelling counts: each answer must match an item name.
  • More items recalled means more points. The whole tray earns 200.
All rules

Memorize the items, then type all you remember.

Points grow with every item you recall: the whole tray earns 200, half of it 75.

2–20 players per room.

Make it yours

The host can adjust these before the game starts.

Room settings

  • Rounds 1–12, default 3
  • Pace Options: Relaxed · Normal · Quick. Default: Normal
  • Seconds to memorize 5–180, default 12
  • Seconds to recall 10–300, default 30

Custom content

  • Custom items Bring your own (at least 12, each ≤ 40 chars)
