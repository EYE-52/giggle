Roast Toast

Friendly burns only

  • 3–20 players
  • Everyone plays
  • Customizable

How to play

Goal Write the friendly roast that gets the most love.

  • Each round names one target. Everyone else writes one roast line.
  • Keep it kind: roast the habit, not the person.
  • Vote for the funniest anonymous roast, but not your own.
  • The room favorite earns 100. The target picks a favorite for 100 more.
  • By default, everyone takes one turn as the target.
All rules

Write a friendly roast for the target.

Vote on anonymous entries except your own.

The room favorite earns 100 points; the target’s favorite earns 100 more.

3–20 players per room.

Make it yours

The host can adjust these before the game starts.

Room settings

  • Rounds 1–12, default Auto (one per player)
  • Pace Options: Relaxed · Normal · Quick. Default: Normal
  • Seconds to write 15–600, default 60

Custom content

  • Custom starters Bring your own (at least 3)
