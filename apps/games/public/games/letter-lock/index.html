Letter Lock

Six rows. One secret. Beat the room.

  • 2–20 players
  • Everyone plays
  • Customizable

How to play

Goal Crack the secret word before your six rows run out.

  • Type a dictionary word with five letters, then check it.
  • A check means the right spot; a dot means the letter is elsewhere.
  • Solving scores 100; spare rows and the first solve add up to 100.
  • Three right spots in one row earn 50 if you do not solve.
All rules

Race to solve the same five-letter word in six tries and 120 seconds.

Each row marks letters as right spot, in word, or absent; repeated letters only count as often as they occur.

Other players see your marks, never your letters.

Solve for 100, plus 10 per unused try and 50 for the first solver, with extras capped at 100.

A failed board with at least three right spots in one row gets 50.

The host can press Next after results.

2–20 players per room.

Make it yours

The host can adjust these before the game starts.

Room settings

  • Rounds 1–12, default 5
  • Pace Options: Relaxed · Normal · Quick. Default: Normal
