Scattergories

Letter, lists, unique wins

  • 2–20 players
  • Everyone plays
  • Customizable

How to play

Fill every category with a word that starts with the round letter before time runs out.

Each answer nobody else wrote earns 40 points (all five: 200).

2–20 players per room.

Make it yours

The host can adjust these before the game starts.

Room settings

  • Rounds 1–12, default 3
  • Pace Options: Relaxed · Normal · Quick. Default: Normal
  • Seconds to write 30–180, default 60

Custom content

  • Custom categories Bring your own (at least 5, each ≤ 40 chars)
  • Custom letters Bring your own (at least 5, up to 26, each ≤ 2 chars)

Start a room

Pick a name, create a room, and invite your friends. No account needed.
