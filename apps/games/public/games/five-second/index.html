5 Second Rule

Name 3 in 5 seconds

  • 3–20 players
  • Everyone plays
  • Customizable

How to play

Name 3 things in the category within 5 seconds.

The room judges pass or fail: a pass is worth 100, and a streak of passes adds up to 100 more.

3–20 players per room.

Make it yours

The host can adjust these before the game starts.

Room settings

  • Rounds 1–12, default Auto (one per player)
  • Pace Options: Relaxed · Normal · Quick. Default: Normal
  • Seconds to vote 5–60, default 15

Custom content

  • Custom categories Bring your own (at least 5, each ≤ 60 chars)

Pick a name, create a room, and invite your friends. No account needed.
