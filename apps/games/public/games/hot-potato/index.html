Hot Potato

Name it. Pass it. Hope.

  • 2–16 players
  • Everyone plays
  • Customizable

How to play

Goal Keep your lives by passing before the hidden fuse pops.

  • Answers need 2–30 characters and cannot repeat this round.
  • The server checks repeats and basic text only. The room judges the category.
  • Every player except the answer writer can challenge. More than half must agree.
  • The fuse keeps burning while answers are challenged.
All rules

Type a fresh answer for the category to pass the potato to the next seat.

The hidden fuse lasts 20–45 seconds at Normal pace.

Whoever holds it when it pops loses one of 3 lives.

Tap Nope within 4 seconds to challenge an answer: a strict majority of the other players sends it back.

The last player with lives earns 300 points, then 200 and 100 by elimination order.

Players judge whether answers fit the category.

2–16 players per room.

Make it yours

The host can adjust these before the game starts.
